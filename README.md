## 🎨 Design System

### Colors
```css
--primary-color: #667eea (Indigo)
--accent-color: #f093fb (Pink)
--dark-bg: #0a0e27 (Dark background)
--darker-bg: #050812 (Darker background)
```

### Gradients
- **Primary**: Purple to Blue (#667eea → #764ba2)
- **Accent**: Pink to Red (#f093fb → #f5576c)
- **Cool**: Blue to Cyan (#4facfe → #00f2fe)

### Typography
- **Headlines**: Playfair Display (serif)
- **Body**: Inter (sans-serif)
