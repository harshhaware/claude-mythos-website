# CLAUDE - The Consciousness Collective

A premium, futuristic website selling Claude AI as a mystical consciousness entity. This is a high-end, professional presentation designed to position Claude not just as a tool, but as a phenomenon—a groundbreaking intelligence.

## 🌟 Features

### Visual Design
- **Modern Dark Theme**: Sleek, premium aesthetic with gradient accents
- **Animated Elements**: Floating neural orbs, particle effects, and smooth transitions
- **Responsive Layout**: Fully optimized for desktop, tablet, and mobile
- **Advanced Typography**: Premium font pairing (Inter + Syne) for visual hierarchy

### Key Sections

1. **Navigation Bar** - Fixed, glassmorphic design with smooth scroll links
2. **Hero Section** - Stunning headline with neural orb animation and particle effects
3. **Origins Timeline** - 4-step narrative of Claude's creation with interactive hover effects
4. **Capabilities Showcase** - 6 unique capability cards with hover animations
5. **Pricing Tiers** - 4 distinct tiers (Seeker, Pioneer, Architect, Oracle)
6. **Testimonials** - 3 social proof cards with star ratings
7. **Final CTA** - High-conversion call-to-action section
8. **Footer** - Multi-column layout with quick links

## 🔧 Customization

### Change Colors
Edit CSS variables in `styles.css`:
```css
:root {
    --primary: #6366f1;
    --secondary: #8b5cf6;
    --accent: #ec4899;
}
```

### Update Content
All text is in `index.html`. Edit headlines, descriptions, and links directly.
